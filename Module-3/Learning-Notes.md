# Module 3 Learning Notes — Lists and Material Design

## Key concepts

- Kotlin data classes model structured UI content clearly.
- `LazyColumn` renders list items efficiently and is preferred for long scrollable lists.
- Material components such as `Card` provide consistent visual behavior and hierarchy.
- UI animation can reinforce a state change when it is purposeful and restrained.
- Accessibility semantics give assistive technologies meaningful descriptions and actions.
- Collections and higher-order functions make it easier to prepare data for list-based UI.

## Practical implementation

The Developer Affirmations application displays a collection using `LazyColumn`. Each card expands when selected, uses `animateContentSize()` to make the transition readable, and includes a semantics description for accessibility.
