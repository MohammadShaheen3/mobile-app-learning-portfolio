# Run, Evidence, and Submission Guide

## 1. Open the portfolio in Android Studio

Open the repository root (`mobile-app-learning-portfolio`) as the project. Allow Gradle synchronization to finish. Use JDK 17 if Android Studio asks for a Gradle JDK.

The four runnable application modules are:

- `module1BusinessCard`
- `module2TipCalculator`
- `module3Affirmations`
- `module4MyCity`

Select one module at a time in the Android Studio run configuration and launch it on an emulator or Android device.

## 2. Capture application evidence

Save screenshots using the exact filenames listed in each module's `Screenshots/README.md`. The evidence should show the real application output from your emulator/device.

## 3. Complete the official learning quizzes

Use the official Android Basics with Compose course and complete all three pathways in Units 1–4. Complete each pathway quiz while signed into the Google/Android Developers account linked to your developer profile. The target set is 12 badges.

Save each badge screenshot using the exact filename listed in the relevant `Badge-Evidence/README.md`.

## 4. Replace portfolio placeholders

Search the repository for `ADD-` and replace:

- `ADD-STUDENT-ID`
- `ADD-ANDROID-DEVELOPER-PROFILE-URL`

Also replace the example contact values in Module 1 if you want your actual public portfolio details displayed in the app.

## 5. Run the Module 2 tests

In Android Studio, right-click `TipCalculatorTest` and run it. Capture the passing test result as `Module-2/Screenshots/04-unit-tests.png`.

## 6. Capture Module 4 wide-screen evidence

Run `module4MyCity` using a tablet or resizable emulator. Increase the window width until the app displays categories and recommendations side-by-side. Save the screenshot as `Module-4/Screenshots/04-mycity-wide.png`.

## 7. Continue genuine Git commits

As you add screenshots and badge evidence, continue making meaningful commits. Example messages:

```text
Add Module 1 emulator evidence
Document Unit 2 badge achievements
Add passing Tip Calculator test evidence
Capture responsive My City tablet layout
Complete badge evidence for Android Basics with Compose
Finalize portfolio links and submission summary
```

## 8. Final PDF

The Moodle PDF must contain:

1. GitHub repository URL
2. Android Developer profile URL
3. Badge summary

Use `Submission/Badge-Summary.md` as the final source. Replace the placeholders before exporting it to PDF.
